# @kineticui/icons

348 original 24 px stroke icons as tree-shakable React components.

```bash
npm i @kineticui/icons
```

```tsx
import { SearchIcon, Icon } from "@kineticui/icons";

<SearchIcon size={18} strokeWidth={1.75} />
<Icon name="search" />
```

Browse and copy icons at https://kinetic-ui.vercel.app/icons.

Docs: https://kinetic-ui.vercel.app
