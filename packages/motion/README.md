# @kineticui/motion

Motion effects for Kinetic UI: Spotlight Card, Border Beam, Marquee, Text Scramble, Parallax, Confetti and more.

```bash
npm i @kineticui/motion @kineticui/core
```

```tsx
import { Marquee, NumberTicker, SpotlightCard } from "@kineticui/motion";

<NumberTicker value={4210} />
```

Every effect respects `prefers-reduced-motion`.

Docs: https://kinetic-ui.vercel.app

Part of [Kinetic UI](https://github.com/Chaitanya-NK/kinetic-ui). MIT licensed.
