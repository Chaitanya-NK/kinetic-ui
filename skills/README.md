# Kinetic UI Agent Skill

`kinetic-ui/` teaches AI coding assistants the library's conventions: reuse existing components, install the way the project already does, style with tokens, respect reduced motion and keep things accessible. It's generated from the registry by `scripts/gen-skill.mjs` (part of `npm run registry`), so don't edit it by hand.

Install it:

- **Claude Code and Cursor**: `npx @kineticui/cli skill` in your project (writes `.claude/skills/kinetic-ui/` and `.cursor/rules/kinetic-ui.mdc`).
- **Claude app**: download https://kinetic-ui.chaitanya-nk.com/kinetic-ui-skill.zip, then Customize → Skills → + → Create skill → Upload a skill.
